# learn-tutor-starter

The sample repository for **Build with Learn**: one folder per step and per recipe. Each folder is complete and runnable, with a README and an `.env.example` (never a real key), so you can start at any step.

| Folder | Step or recipe | Page |
| --- | --- | --- |
| `01-first-tutor` | Step 1: Your first tutor in ten minutes | https://developers.foreverlearning.ai/build/1/ |
| `02-four-kinds-of-help` | Step 2: The four kinds of help | https://developers.foreverlearning.ai/build/2/ |
| `03-photos-of-work` | Step 3: Photos of handwritten work | https://developers.foreverlearning.ai/build/3/ |
| `04-remember-the-learner` | Step 4: Remember the learner | https://developers.foreverlearning.ai/build/4/ |
| `05-safety-status` | Step 5: Show the safety status | https://developers.foreverlearning.ai/build/5/ |
| `embed` | Recipe: Embed Learn in your app (`embed/start` is the app before Learn) | https://developers.foreverlearning.ai/build/embed/ |

More steps and recipes arrive as each one is verified against the release.

Keys never go in this repository. Copy a folder's `.env.example` to `.env`, which Git ignores, and put your key there.

You need Node 24 or later, a developer workspace with Learn, and a server key. The integration guide: https://developers.foreverlearning.ai/docs/learn/
